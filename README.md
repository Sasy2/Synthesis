# Ashesi Degree Audit

A lightweight, purely frontend web application designed to help Computer Science students at Ashesi University track their degree progress, plan remaining semesters, and calculate target CGPAs before meeting with their academic advisor.

## Features
- **Dynamic Degree Checklist**: Automatically populates all required categories, core courses, and electives.
- **Progress Tracking**: Calculates exactly how many credits have been completed and how many remain.
- **Semester Planning**: Automatically distributes remaining credits and determines if a student can graduate on time (maximum 4.5 credits per semester).
- **Target CGPA Calculator**: Determines the exact letter grade a student must average in their remaining courses to reach a specific CGPA goal.
- **Validation & Edge Cases**: Highlights required retakes, accurately processes "P" (Pass) grades without affecting GPA, and handles zero-credit seminars.

## Technologies Used
- HTML5 (Semantic Structure)
- CSS3 (Flexbox/Grid, Mobile-first responsive design, Ashesi color theme)
- Vanilla JavaScript (Pure functions, DOM Manipulation)
*Note: This project is built completely without external libraries, frameworks, or build tools to satisfy strict academic constraints.*

## How to Run
Simply clone the repository and open `index.html` in any modern web browser. No local server or build environment is required.
